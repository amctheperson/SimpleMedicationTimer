Simple Medication Timer (The Back-end)

A back-end for a WIP Android app that displays remaining time medications a user takes is actively providing mental clarity.

The back-end of this Android App will store/access local data involving User and Medication objects as JSON files.

Disclaimers:
* This application will be merely a medication management tool, all medication taken by users should ultimately be taken as prescribed by a doctor. 
* Local files will be encrypted in the final version for privacy reasons.

Notes:
* The back-end for this application was implemented in Java using VIM as an editor. Thus, this back-end is formatted for an 80x60 window of VIM.
* Development of this back-end began in Jan 2026 and was completed around April 2026.
